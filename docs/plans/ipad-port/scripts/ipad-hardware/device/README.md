A query-status capture is valid only when it contains exactly six newline-terminated, printable-ASCII lines in the documented fixed-label grammar. Numeric statuses expose whether each `ioreg` process returned successfully without revealing its raw output.

## Review boundary

The scripts do not consume caller-supplied arguments or stdin. They use absolute paths for `ioreg` and `grep`; fixed-format `command printf` calls produce the final output. Once the script begins executing, stderr is closed before any discovery or path-bearing command.

Shell, interpreter, and SSH startup occurs before the script's first command and is outside its control. The separately reviewed invocation must use a fresh noninteractive POSIX `sh` selected from its reviewed absolute-path allowlist, disable tracing and verbose modes, close transport stderr before interpreter startup, and validate the complete output grammar.

The proposed local invocation is `scripts/ipad-hardware/run-approved-readonly-device-probe.sh`. It is not approved merely because the payloads are approved: its exact revision and selected command require separate adversarial review. When that review explicitly confirms no reachable persistent device write, the standing read-only authorization applies without separate owner approval.

The script constructs and locally audits a one-member ustar archive under an empty environment, with fixed ownership labels and a fixed `2020-01-01 00:00:00 UTC` member mtime. An isolated local feeder opens that mode-`0400` archive once with no symlink following, buffers at most 1 MiB, verifies the pinned archive SHA-256, and emits those same buffered bytes to the observed rootless GNU tar. Remote extraction uses `--keep-old-files`, suppresses owner/permission restoration, and sets umask `077`. A local isolated watchdog limits SSH to 60 seconds. It requires the exact three-line success grammar, binds the downloaded JSON to the probe-reported byte hash, size-caps the local download, and validates the fixed invocation fields before preserving the report locally. A kill or timeout can leave a partial or complete temporary file; any cleanup requires separate review and approval.

The iPad has no reviewed Python/FD-execution helper and Darwin exposes no usable `fexecve`, so the launcher must execute by pathname. A hostile process running concurrently as the same device user could theoretically replace and restore that pathname inside the narrow launch window. Immediate type/access checks plus complete pre/post SCP hashes detect ordinary replacement but cannot eliminate that same-user adversarial race. If the local watchdog closes SSH, device-side session teardown is expected to terminate the foreground probe, but a process that survives teardown could continue and finish the report write.
